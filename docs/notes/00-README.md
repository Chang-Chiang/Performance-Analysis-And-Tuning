## 三、三条贯穿全篇的主线

1. **闭环工作流**：度量基线 → 热点定位 → TMA 分瓶颈 → 开对应药 → 验证加速比 → 不达预期回③。
2. **两大瓶颈药箱**：`Memory Bound` 靠**局部性/布局/预取**；`Core Bound` 靠**向量化/消依赖/ILP**；`Bad Speculation` 靠**分支/查表**。
3. **杠杆层级**：算法 > 数据结构 > 布局 > 局部性 > 向量化 > 编译开关。**改对本质，一骑绝尘**。

| 组件 | 版本 |
|------|------|

| **GPU** | **NVIDIA RTX 5070 Ti**（Blackwell sm_120, 70 SM, 16 GB）|
| 编译器 | gcc 15.2.0 / clang 21.1.8 / **nvcc CUDA 13.4** |
| 工具链 | `perf 7.0.14`, `cmake 4.2.3`, OpenMP 可用 |
| **TBB** | **oneAPI TBB 2023.1**（`pkg-config tbb` 指向它；另有 apt `libtbb-dev` 2022.3）|
| MPI | Intel oneAPI MPI 2021.18 |

**⚠️ 本机启动 MPI 的正确姿势**：`mpirun` 因 sandbox 无法孵化 `hydra_bstrap_proxy`，改用：
```bash
mpiexec.hydra -bootstrap ssh -n N ./app   # 需 ssh localhost 免密
```

**实战实验预构建**：`TMA/memory_bound/loop_interchange_1/build_ijk/` 与 `build/` 已分存基线 + 优化两个 `lab` 二进制，可直接对比（详见 `41-实战-loop_interchange_1.md`）。

**换机器请重新采数字**——加速比与硬件强相关（见 `30 测量纪律手册`）。
