TMA 性能优化实验知识库

本文档基于 TMA/ 目录（源自 perf-ninja 实战练习）整理。实验按 Top-down Microarchitecture Analysis 的瓶颈层级分类，每个实验以「优化前 baseline / 优化后 solution」分栏对比展示代码形态、优化手法与实测加速比。

🧠 Memory Bound · 访存瓶颈 ⚙️ Core Bound · 计算瓶颈 🎲 Bad Speculation · 分支预测 🛠️ Misc · 编译器优化

来源目录：TMA/（memory_bound · core_bound · bad_speculation · misc）。每个实验包含 solution.cpp（优化后）、validate.cpp（含 baseline 参照实现）、bench.cpp（Google Benchmark）。

加速比为 README 记录的参考值，实际取决于硬件与输入。分析命令：perf stat --topdown / toplev.py；构建：cmake -DCMAKE_BUILD_TYPE=Release ..。
