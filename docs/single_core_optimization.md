### 4. 单核优化

- **指令级并行**

  **指令流水线**

  现代处理器采用流水线设计，将指令执行划分为多个阶段（取指、译码、执行、访存、写回），每个阶段在对应的功能部件中完成，利用指令重叠执行来加速处理速度。

  ```
  指令1: 取指 → 译码 → 执行 → 访存 → 写回
  指令2:        取指 → 译码 → 执行 → 访存 → 写回
  指令3:               取指 → 译码 → 执行 → 访存 → 写回
  ```

  流水线超过 5-6 级称为**超级流水线**（深度流水线），可提升主频，但级数越多，指令间相关性导致冲突的风险越大。

  **指令相关性**

  指令间的相关性会导致流水线停顿，主要有三种类型：

  **数据相关性**：指令 B 依赖指令 A 的计算结果。

  ```asm
  mul R1, R2, R3    # 指令1: 写 R1
  add R3, R0, R4    # 指令2: 读 R3（与指令1无关），写 R3
  sub R6, R5, R7    # 指令3: 读 R5、R7
  sub R9, R8, R10   # 指令4
  ```

  通过调整指令顺序可消除数据相关性：

  ```asm
  mul R1, R2, R3    # 指令1
  sub R6, R5, R7    # 指令3（移前，与指令1无依赖）
  sub R9, R8, R10   # 指令4
  add R3, R0, R4    # 指令2（移后）
  ```

  **反相关性**：指令 A 在前读某寄存器，指令 B 在后写同一寄存器。交换顺序会影响正确性。

  ```asm
  mul R1, R2, R3    # 指令A: 读 R3
  sub R4, R5, R3    # 指令B: 写 R3（反相关于 A）
  ```

  **输出相关性**：两条指令写同一寄存器，交换顺序会影响最终结果。

  ```asm
  mul R1, R2, R3    # 指令A: 写 R1
  sub R4, R5, R1    # 指令B: 读 R1
  ```

  **控制相关性**：指令的执行受控于分支指令的结果。

  ```asm
  bne R1, R2, Label  # 指令1: 条件跳转
  add R3, R4, R5     # 指令2: 是否执行取决于指令1
  mul R5, R0, R6     # 指令3
  Label: sub R1, R6, R6  # 指令4
  ```

  **消除控制相关的方法：**

  **控制语句外提**：将循环不变的判断条件外提到循环外，减少循环内的控制相关。

  ```c
  // 优化前：每次循环都判断 an > 10
  for (int i = 0; i < N; i++) {
      if (an > 10)
          a[i] = c[i];
      else
          a[i] = d[i];
      m[i] = n[i];
  }

  // 优化后：判断条件外提
  if (an > 10) {
      for (int i = 0; i < N; i++) { a[i] = c[i]; m[i] = n[i]; }
  } else {
      for (int i = 0; i < N; i++) { a[i] = d[i]; m[i] = n[i]; }
  }
  ```

  **if 转换**：将条件分支转换为条件赋值，把控制依赖转为数据依赖。

  ```c
  // 优化前：控制相关
  for (int i = 0; i < N; i++) {
      if (i * 2 > 2)
          c[i] = C0;
      else if (i * 2 < 2)
          c[i] = C1;
      else
          d[i] = D0;
  }

  // if 转换后：数据依赖
  for (int i = 0; i < N; i++) {
      c[i] = (i * 2 > 2) ? C0 : c[i];
      c[i] = (!(i * 2 > 2) && (i * 2 < 2)) ? C1 : c[i];
      d[i] = (!(i * 2 > 2) && !(i * 2 < 2)) ? D0 : d[i];
  }
  ```

  if 转换后还可进一步合并条件语句：

  ```c
  // 转换后
  for (int i = 0; i < N; i++) {
      a[i] = (i * 2 > 2) ? C0 : a[i];   // S4
      a[i] = !(i * 2 > 2) ? C1 : a[i];  // S5
  }
  // 合并后
  for (int i = 0; i < N; i++) {
      a[i] = (i * 2 > 2) ? C0 : C1;     // S6
  }
  ```

  **指令多发射**

  多发射处理器每个周期可发射多条指令（一般 2-4 条），使每个时钟周期的指令数倍增。多发射方法有**超标量**和**超长指令字（VLIW）**两种：

  | 特性     | 超标量（Superscalar）    | 超长指令字（VLIW）    |
  | -------- | ------------------------ | --------------------- |
  | 并行指定 | 执行阶段由处理器硬件指定 | 编译阶段由编译器指定  |
  | 硬件复杂 | 高                       | 低                    |
  | 配合技术 | 通常配合乱序执行         | 由编译器/优化人员指定 |
  | 典型代表 | x86、ARM                 | DSP（如 TI C6000）    |

  **超标量与乱序执行**

  乱序执行在指令间不存在相关性的前提下，通过调整指令执行顺序提升并行性。处理器通过重排序缓冲区分析指令相关性，先用寄存器重命名去除相关性，再由指令调度器调整执行顺序。

  ```asm
  # 优化前：指令2 依赖指令1 的结果 R1，无法与指令1 并行
  add R3, R2, R1    # 指令1: 写 R1
  mul R1, R0, R4    # 指令2: 读 R1（依赖指令1）
  mul R6, R5, R7    # 指令3: 无依赖

  # 乱序执行：交换指令2 和指令3，指令1 和指令3 可并行执行
  add R3, R2, R1    # 指令1
  mul R6, R5, R7    # 指令3（无依赖，可并行）
  mul R1, R0, R4    # 指令2（等待指令1 完成）
  ```

  **超长指令字**

  VLIW 处理器每条超长指令装有多条常规指令，同一时刻发射。以 TI C6000 DSP 为例，包含 8 个功能部件（.L1、.S1、.M1、.D1、.D2、.M2、.S2、.L2），可通过 `‖` 指令指定并行执行：

  ```asm
  ADD .S1 A1, A2, A1
  ‖ ADD .S2 A4, A5, A4      # 与上条同周期
  ‖ MUL .M1 B1, B2, B1      # 与上条同周期
  ‖ MUL .M2 B4, B5, B4
  ‖ SUB .L1 A3, A6, A3
  ‖ SUB .L2 B3, B6, A3
  ‖ LDDW .D1T1 *A7++, A9:A8
  ‖ LDDW .D2T2 *B7++, B9:B8
  ```

  充分利用 8 个功能部件可在一个时钟周期内完成 8 条指令，发挥处理器的指令级并行优势。

  **循环展开与指令调度**

  实际程序中受限于指令相关性和指令数量，往往不能充分发挥指令级并行。通过循环展开增大循环体内指令数量，编译器可在更多指令间进行调度，选择更优的并行发射组合。

  ```c
  // 优化前：循环体指令少，难以调度
  for (i = 0; i < N; i++)
      for (j = 0; j < N; j++) {
          c[i][j] = 0;
          for (k = 0; k < N; k++)
              c[i][j] += a[i][k] * b[k][j];
      }

  // 优化后：循环展开后，编译器可在更多指令间调度并行
  ```

- **数据级并行**

  数据级并行是指处理器同时处理多条数据的并行方式。大部分处理器采用 **SIMD（Single Instruction Multiple Data）** 向量扩展，将多次装载的标量数据一次性装载到向量寄存器中，通过一条向量指令并行处理。将标量代码转换为向量代码的过程即为**向量化**。

  获得向量程序的两种方式：
  1. 程序设计人员手动编写向量代码
  2. 借助编译器的向量化编译自动生成

  常用 Intel SSE 向量指令（128 位）：

  | 操作         | 指令               |
  | ------------ | ------------------ |
  | 对齐读内存   | `_mm_load_ps`      |
  | 不对齐读内存 | `_mm_loadu_ps`     |
  | 对齐写内存   | `_mm_store_ps`     |
  | 不对齐写内存 | `_mm_storeu_ps`    |
  | 向量加       | `_mm_add_ps`       |
  | 向量减       | `_mm_sub_ps`       |
  | 向量乘       | `_mm_mul_ps`       |
  | 向量设置     | `_mm_set_ps`       |
  | 向量混洗     | `_mm_shuffle_ps`   |
  | 向量收集     | `_mm_i32gather_ps` |

  **向量化程序编写**

  向量化的本质是重写程序，使其同时对多个数据进行相同操作。可从循环、基本块、函数等层次发掘数据并行性。

  **1. 循环的向量化**

  将多次循环迭代合并为一次向量操作：

  ```c
  // 标量版本
  for (int i = 0; i < N; i++)
      a[i] = b[i];

  // 向量化版本：每次处理 4 个元素
  for (int i = 0; i < N / 4; i++) {
      __m128 v = _mm_load_ps(b + i * 4);
      _mm_store_ps(a + i * 4, v);
  }
  ```

  多层循环一般选择最内层循环向量化，以矩阵乘为例：

  ```c
  for (int i = 0; i < N; i++) {
      for (int j = 0; j < N; j++) {
          __m128 vc = _mm_set_ps(0, 0, 0, 0);
          for (int k = 0; k < N; k += 4) {
              __m128 va = _mm_load_ps(&a[i][k]);
              __m128 vb = _mm_set_ps(b[k+3][j], b[k+2][j], b[k+1][j], b[k][j]);
              vc = _mm_add_ps(_mm_mul_ps(va, vb), vc);
          }
          float sum[4];
          _mm_store_ps(sum, vc);
          c[i][j] = sum[0] + sum[1] + sum[2] + sum[3];
      }
  }
  ```

  当最内层循环存在依赖且无法通过循环交换消除时，可考虑**外层循环向量化**：

  ```c
  for (int i = 0; i < N; i++) {
      for (int j = 0; j < N; j += 4) {
          __m128 sum = _mm_set_ps(0, 0, 0, 0);
          for (int k = 0; k < N; k++) {
              __m128 vb = _mm_load_ps(&b[k][j]);
              __m128 va = _mm_set_ps(a[i][k], a[i][k], a[i][k], a[i][k]);
              sum = _mm_add_ps(_mm_mul_ps(va, vb), sum);
          }
          _mm_store_ps(&c[i][j], sum);
      }
  }
  ```

  **2. 基本块的向量化**

  基本块级向量化从指令级并行中挖掘数据级并行，核心概念是**打包**（将同构语句组成向量）和**拆包**。非同构语句需先转换为同构语句：

  ```c
  // 非同构
  for (int i = 0; i < N; i += 2) {
      C[i]     = B[i] * 0.5 + 2;       // S1
      C[i + 1] = B[i + 1] + 1;         // S2
  }

  // 转换为同构
  for (int i = 0; i < N; i += 2) {
      C[i]     = B[i] * 0.5 + 2;
      C[i + 1] = B[i + 1] * 1 + 1;     // 与 S1 同构
  }
  ```

  循环展开可增加基本块内语句数量，配合基本块向量化：

  ```c
  // 循环展开 2 次后向量化
  __m128 z  = _mm_set_ps(3, 2, 1, 0);
  __m128 z1 = _mm_set_ps(1, 0, 5, 4);
  __m128 z2 = _mm_set_ps(5, 4, 3, 2);
  for (int i = 0; i < N; i += 12) {
      _mm_storeu_ps(&c[i],     z);
      _mm_storeu_ps(&c[i + 4], z1);
      _mm_storeu_ps(&c[i + 8], z2);
  }
  ```

  **3. 函数的向量化**

  将标量函数改为向量函数，参数和返回值都为向量：

  ```c
  // 标量函数
  float fun1(float x, float y) { return x * y; }
  for (int i = 0; i < N; i++)
      a[i] = fun1(b[i], c[i]);

  // 向量化函数
  __m128 vecfun1(__m128 x, __m128 y) { return _mm_mul_ps(x, y); }
  for (int i = 0; i < N; i += 4) {
      __m128 vb = _mm_loadu_ps(&b[i]);
      __m128 vc = _mm_loadu_ps(&c[i]);
      _mm_storeu_ps(&a[i], vecfun1(vb, vc));
  }
  ```

  **4. 分支的向量化**

  **if 转换**：将控制依赖转为数据依赖，利用向量条件选择指令（`select`）实现。`dst = select(src1, src2, mask)`：mask 为 1 时取 src2，否则取 src1。

  ```c
  // if 转换后
  for (int i = 0; i < N; i++) {
      v[i] = (a[i] > 0 && a[i] > b[i]) ? w[i] : v[i];
      p[i] = (a[i] > 0 && a[i] > b[i] && b[i] > 10) ? m[i] : p[i];
  }

  // 向量化
  for (int i = 0; i < N; i += 4) {
      __m128 va = _mm_loadu_ps(&a[i]);
      __m128 vb = _mm_loadu_ps(&b[i]);
      __m128 vw = _mm_loadu_ps(&w[i]);
      __m128 vv = _mm_loadu_ps(&v[i]);
      __m128 v0 = _mm_set_ps(0, 0, 0, 0);
      __m128 mask = _mm_and_ps(_mm_cmpgt_ps(va, v0), _mm_cmpgt_ps(va, vb));
      vv = _mm_add_ps(_mm_and_ps(vw, mask), _mm_andnot_ps(mask, vv));
      _mm_storeu_ps(&v[i], vv);
  }
  ```

  当基本块内同构语句足够多时，可**直接 SIMD 向量化**，无需生成条件语句指令。

  **5. 归约的向量化**

  归约操作将多个元素归并为单个元素（如求和）：

  ```c
  // 标量归约
  for (int j = 0; j < N; j++)
      sum = sum + a[j];

  // 向量化归约：利用水平加法指令
  for (int i = 0; i < N / 4; i++) {
      __m128 va = _mm_load_ps(a + 4 * i);
      __m128 vh = _mm_hadd_ps(va, _mm_setzero_ps());
      vh = _mm_hadd_ps(vh, _mm_setzero_ps());
      float s[4];
      _mm_storeu_ps(s, vh);
      sum += s[0];
  }
  ```

  归约也可通过**向量移位指令**实现：两次移位 + 两次相加获得结果。

  **6. 合适的向量长度**

  向量寄存器的使用方式：

  | 使用方式   | 说明                       |
  | ---------- | -------------------------- |
  | 满载使用   | 所有槽位有效，充分向量化   |
  | 一端无效   | 部分槽位有效，不充分向量化 |
  | 两端无效   | 部分槽位有效               |
  | 不连续有效 | 间隔槽位有效               |

  不充分向量化适用于：
  1. 平台不支持向量重组指令时
  2. 向量重组指令代价过大时

  不充分向量化的三种方法：

  **掩码内存读写**：标记有效和无效槽位，运算时对齐槽位，写回时避免无效槽位写入。

  **插入/提取**：通过标量读操作将数据存放到标量寄存器，再插入向量寄存器的对应位置。Intel SSE 可用 `_mm_set_ps` 一次加载多个标量值到向量寄存器。

  **加宽向量访存**：当需要的值在内存中连续时，一条加宽向量读指令即可加载。写回时需备份和恢复被误写的相邻数据：

  ```asm
  Load   $f4, w[col+1][0]    # 备份相邻数据
  Vstore $f3, w[col][0]      # 向量写（可能误写 w[col+1][0]）
  Store  $f4, w[col+1][0]    # 恢复相邻数据
  ```

  无效槽位需填充有效数据以避免算术异常，可利用插入指令或混洗指令将有效槽位数据填充到无效槽位。

  **向量化程序优化**

  向量化程序的优化可从以下方面入手：
  1. **数据对齐**：使用对齐内存分配，避免不对齐访存开销
  2. **循环展开**：增大循环体指令数，便于编译器调度
  3. **消除依赖**：使用标量扩展、标量重命名等技术
  4. **选择合适的向量长度**：根据平台特性和数据特点选择充分或不充分向量化
  5. **利用平台特性**：针对目标平台的 SIMD 指令集优化


  **向量化程序优化**

  向量化程序的进一步优化包含以下六个方面。

  **1. 不对齐访存**

  内存对齐访问要求地址 A 对 n 求余等于 0（n 为访存字节数）。不对齐访存需要额外开销，应尽量使用对齐访存指令。

  **循环剥离**：将不对齐的首尾元素剥离，中间部分使用对齐指令：

  ```c
  // 优化前：不对齐访存
  for (int i = 0; i < 100; i++)
      B[i + 1] = A[i + 1] + C;

  // 循环剥离后：首尾不对齐部分单独处理，中间对齐
  for (int i = 0; i < 3; i++)
      B[i + 1] = A[i + 1] + C;
  for (int i = 3; i < 99; i++)
      B[i + 1] = A[i + 1] + C;  // 对齐访存
  for (int i = 99; i < 100; i++)
      B[i + 1] = A[i + 1] + C;
  ```

  **数组填充**：当多维数组最低维长度不是向量长度整数倍时，通过增加最低维长度使其满足对齐要求：

  ```c
  // 优化前：1335 不是 4 的倍数，无法对齐
  for (int i = 0; i < 1335; i++)
      for (int j = 0; j < 1335; j++)
          A[i][j] = A[i][j] * 2;

  // 填充后：1336 是 4 的倍数，可统一使用对齐指令
  for (int i = 0; i < 1335; i++)
      for (int j = 0; j < 1336; j++)
          A[i][j] = A[i][j] * 2;
  ```

  **不对齐指令**：无法确定对齐性时，使用不对齐指令保证正确性：

  ```c
  for (int i = 0; i < N; i += 4) {
      __m128 va = _mm_loadu_ps(&A[i + 2]);
      _mm_storeu_ps(&C[i], va);
  }
  ```

  **2. 不连续访存**

  连续访存可提高访存效率和向量寄存器有效数据比率。对于不连续但有规律的访存，可利用向量重组实现向量化。

  **聚集指令**：使用 `_mm_i32gather_ps` 实现不连续数据收集：

  ```c
  for (int i = 0; i < N; i += 4) {
      a[i] = i + 2;
  }
  // 向量化：使用聚集指令
  for (int i = 0; i < N / 4; i++) {
      __m128 gather = _mm_set_ps(0, 0, 0, 0);
      __m128 v = _mm_i32gather_ps(a + 4 * i, gather, sizeof(float));
      _mm_storeu_ps(b + i, v);
  }
  ```

  **混洗重组**：通过两次对齐访存 + 混洗操作实现不对齐访存：

  ```
  两次对齐访问:  [A[0] A[1] A[2] A[3]]  [A[4] A[5] A[6] A[7]]
  混洗重组后:    [A[2] A[3] A[4] A[5]]
  ```

  ```c
  for (int i = 0; i < N; i += 4) {
      __m128 v1 = _mm_loadu_ps(y + i);
      __m128 v2 = _mm_loadu_ps(y + i + 4);
      // _MM_SHUFFLE(2,0,2,0) 取偶数位，_MM_SHUFFLE(3,1,3,1) 取奇数位
      __m128 vj = _mm_shuffle_ps(v1, v2, _MM_SHUFFLE(2, 0, 2, 0));
      __m128 vo = _mm_shuffle_ps(v1, v2, _MM_SHUFFLE(3, 1, 3, 1));
  }
  ```

  混洗指令还可用于**数据广播填充**，将单个值复制到所有槽位：

  ```c
  for (int i = 0; i < N; i += 4) {
      __m128 vy = _mm_loadu_ps(y + i);
      __m128 vx = _mm_shuffle_ps(vy, vy, 0);  // 广播第一个元素
      _mm_storeu_ps(&x[i], vx);
  }
  ```

  **3. 向量重用**

  向量寄存器含有多个数据项，重用可减少甚至消除访存需求。

  **不对齐访存的重用**：将上一次访存结果与本次对齐访存拼接，避免重复加载：

  ```c
  // 不对齐访存：每次需要加载 4 个元素
  for (int i = 0; i < N; i += 4) {
      __m128 va = _mm_loadu_ps(&A[i + 2]);
      _mm_storeu_ps(&C[i], va);
  }

  // 向量重用：上一次尾部与本次头部拼接
  __m128 va1 = _mm_load_ps(a);
  for (int i = 0; i < N; i += 4) {
      __m128 va2 = _mm_load_ps(&a[i + 4]);
      __m128 v = _mm_shuffle_ps(va1, va2, _MM_SHUFFLE(1, 0, 3, 2));
      _mm_store_ps(&c[i], v);
      va1 = va2;
  }
  ```

  **完全重用**：同一数据被多次使用时，加载一次即可：

  ```c
  // 未重用：vb 和 vc 被加载了两次
  for (int i = 0; i < N; i += 4) {
      __m128 vb = _mm_loadu_ps(b + i);
      __m128 vc = _mm_loadu_ps(c + i);
      _mm_storeu_ps(a + i, _mm_add_ps(vb, vc));
      vb = _mm_loadu_ps(b + i);   // 重复加载
      vc = _mm_loadu_ps(c + i);   // 重复加载
      _mm_storeu_ps(d + i, _mm_sub_ps(vb, vc));
  }

  // 向量重用：加载一次，使用两次
  for (int i = 0; i < N; i += 4) {
      __m128 vb = _mm_loadu_ps(b + i);
      __m128 vc = _mm_loadu_ps(c + i);
      _mm_storeu_ps(a + i, _mm_add_ps(vb, vc));
      _mm_storeu_ps(d + i, _mm_sub_ps(vb, vc));
  }
  ```

  **4. 向量运算融合**

  将多条向量运算指令合并为一条，如将乘法和加法融合为乘加指令（FMA）：

  ```c
  // 优化前：乘法和加法分开
  for (int i = 0; i < N; i += 4) {
      __m128 v1 = _mm_loadu_ps(&b[i]);
      __m128 v2 = _mm_loadu_ps(&c[i]);
      __m128 v3 = _mm_mul_ps(v1, v2);
      __m128 v4 = _mm_loadu_ps(&d[i]);
      __m128 v5 = _mm_add_ps(v4, v3);
      _mm_storeu_ps(&a[i], v5);
  }

  // FMA 融合：乘加合并为一条指令
  for (int i = 0; i < N; i += 4) {
      __m128 v1 = _mm_load_ps(&b[i]);
      __m128 v2 = _mm_load_ps(&c[i]);
      __m128 v3 = _mm_load_ps(&d[i]);
      v3 = _mm_fmadd_ps(v1, v2, v3);  // v3 = v1 * v2 + v3
      _mm_storeu_ps(&a[i], v3);
  }
  ```

  **5. 循环完全展开**

  向量化后继续展开循环，可在发掘数据级并行的基础上进一步发掘指令级并行，同时提升向量寄存器重用。当向量化后循环次数很少时，可完全展开消除循环控制开销：

  ```c
  // 优化前：8 个元素，向量化后仅需 2 次迭代
  for (int i = 0; i < 8; i++)
      B[i] = A[i];

  // 完全展开：消除循环控制结构
  __m128 v1 = _mm_load_ps(&A[0]);
  _mm_store_ps(&B[0], v1);
  v1 = _mm_load_ps(&A[4]);
  _mm_store_ps(&B[4], v1);
  ```

  **6. 全局不变量合并**

  向量化会引入向量类型的循环不变量，需将其移到循环外。多个循环使用相同的向量常数时，可在更大范围内合并：

  ```c
  // 优化前：V1 在每个循环内重复创建
  for (int i = 0; i < N; i += 4) {
      V1 = _mm_set_ps(C, C, C, C);  // 每次迭代都创建
      V2 = _mm_load_ps(&b[i]);
      _mm_store_ps(&a[i], _mm_mul_ps(V1, V2));
  }
  for (int i = 0; i < N; i += 4) {
      V1 = _mm_set_ps(C, C, C, C);  // 重复创建
      V2 = _mm_load_ps(&x[i]);
      _mm_store_ps(&d[i], _mm_add_ps(V1, V2));
  }

  // 优化后：不变量外提 + 全局合并
  V1 = _mm_set_ps(C, C, C, C);
  for (int i = 0; i < N; i += 4) {
      V2 = _mm_load_ps(&b[i]);
      _mm_store_ps(&a[i], _mm_mul_ps(V1, V2));
  }
  for (int i = 0; i < N; i += 4) {
      V2 = _mm_load_ps(&x[i]);
      _mm_store_ps(&d[i], _mm_add_ps(V1, V2));
  }
  ```
