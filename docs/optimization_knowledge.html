本文档基于 basis/ 目录下的示例代码整理，系统归纳语句级、循环、指令级并行、访存、过程内、数据结构与算法等常见优化手段，采用「优化前 / 优化后」分栏对比的方式，直观展示每种技术的代码形态、原理与收益。

来源目录：basis/（Statement · Loop · ILP · Memory · Intraprocedural · DataStructure · Algorithm · Compiler · Measure）

说明：代码片段为便于对比作了精简，完整可编译版本请查看对应源文件。编译选项通常为 g++ -O2（向量化示例需 -msse / -mavx2，OpenMP 示例需 -fopenmp）。
